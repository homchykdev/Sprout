# FitQuest Pro

Создай красивое современное удобное приложение для спортивных тренировок для меня. Мне очень важно чтобы оно довольно навязчиво напоминало о тренировках, мотивировало, превращало её в игру ради прогресса, как это делает duolingo с изучением языков, только мне надо для занятий спортом и ещё чтобы сильнее его мотивировало. Но при этом важно чтобы было всё нужное как в хорошем приложении для занятий спортом, то есть изменяемая библиотека упражнений(за основную берётся библиотека по musclewiki free api key, а там дальше пользователь может сам добавить то что ему надо). Я хочу добавить возможность изменения и расширения библиотеки с помощью пользовательского api ai key (google gemini api, openai compatible api), а так же составление персональных тренировок и планов тренировок. Во время тренировки упражнения идут последовательно по очереди, на экране крупным планом видео как выполнять упражнение, количество повторов или таймер выполнения(в зависимости от упражнения), краткое описание что делать и как не совершать ошибки при выполнении. После тренировки короткая статистика и что то мотивирующее, как это сделано в duolingo после урока. В приложении есть тепловая карта нагрузки на части тела и советы что можно улучшить(до нагрузить что то, добавить больше растяжки/кардио и тд.). Есть гибкое расписание тренировок - я ставлю предположительные дни когда буду заниматься но если именно в этот конкретный день я не выполню план он просто перенесётся на этой неделе на следующий день. Есть возможность сделать "отпуск" - это полезно если долго без перерыва занимаешься тренировками или нужно куда то поехать. По дизайну: современный, с плавными анимациями, приятный, дорогой вид; ориентиры по дизайну на правила и стиль дизайна apple, новый стиль duolingo; нет сильных градиентов, элементы логичные, удобно расположенные, плавные линии элементов с закруглением, чёткие шрифты. Панель настроек вынесена в отдельное меню или скрыто за иконкой. Приложение должно быть оптимизированным, не занимать много места и удобным. Не обязательно использовать только Android Kotlin - если для проекта лучше другой язык программирования, то выбирай тот что лучше. Задавай вопросы для лучшего результата. Пользуйся скиллами чтобы знать как и что делать.
