# План: контролируемый retry для разбора YouTube-видео + отдельная кнопка «Из YouTube»

## Проблема (расследование)

- `aiSplitWorkout` (`src/lib/ai.functions.ts:294–359`) вызывает `@google/genai` без
  `httpOptions`: SDK по умолчанию сам ретраит 408/429/5xx — до 5 попыток с экспоненциальной
  паузой. Каждая попытка — полный разбор видео моделью (30–90 с), итого до 5–10 минут
  «невидимой» загрузки; цикл ротации ключей (строка 306) умножает на число ключей.
  Таймаута нет → пользователь видит «бесконечное ожидание».
- При ошибке 503 (перегружена модель) цикл выходит и делает `throw last` (строка 357):
  наружу уходит сырой `JSON.stringify` тела ошибки SDK — `{"error":{"code":503,...}}`
  (то, что видел пользователь). Дружелюбного текста для 503 нет.
- Усталую модель загрузкой объясняет запрос пользователя: кнопка «ИИ» открыла диалог
  с двумя табами («Словами» / «YouTube-видео»), YouTube-флоу спрятан внутри.

## Что делаем

### 1. Сервер: контролируемый retry и понятные ошибки (`src/lib/ai.functions.ts`)

- `new GoogleGenAI({ apiKey, httpOptions: { timeout: 180_000, retryOptions: { attempts: 1 } } })` —
  отключаем скрытые ретраи SDK, ставим жёсткий таймаут (3 мин на попытку, ролик длинный).
- Свой retry в обработчике ошибок:
  - `429` → ключ исчерпан → ротация к следующему ключу (как раньше);
  - `503`/`500` → модель перегружена → **одна** повторная попытка через 8 с (ротация ключей
    при 503 бессмысленна — проблема не в ключе), потом бросаем ошибку;
  - после цикла, если был 503 → «Модель Gemini сейчас перегружена. Попробуйте через
    несколько минут или выберите другую модель в настройках» вместо сырого JSON;
  - `429`-финал → «Лимиты исчерпаны…» (как было).
- Попутно (в этом же файле): `inputValidator()` → `validator()` — убрать deprecated
  ворнинги из терминала (то же в `src/lib/ffmpeg.functions.ts`).

### 2. UI: отдельная кнопка «Из YouTube» (`src/routes/library.tsx`)

- В шапке `LibraryContent` три кнопки: «Своё» («+»), **«Из YouTube»** (иконка
  `Youtube`/`MonitorPlay` из lucide-react), «ИИ» (Sparkles).
- «Из YouTube» (как раньше, до слияния табов): открывает отдельный `Dialog` с уже
  готовым `AiYoutubeTab` (компонент менять не нужно). Закрытие диалога, ссылка на
  ключи/провайдер — уже внутри `AiYoutubeTab`.
- «ИИ» остаётся только «Словами»: из `AiDialog` убираем переключатель табов и
  `AiYoutubeTab` (диалог упрощается до одного таба) — дубликации не остаётся.
- `plans.tsx` переиспользует `LibraryContent`, поэтому кнопка появится и там
  автоматически — отдельной правки не требует.

## Файлы

- `src/lib/ai.functions.ts` — retry/timeout/сообщения, `validator()`.
- `src/lib/ffmpeg.functions.ts` — только `inputValidator()` → `validator()`.
- `src/routes/library.tsx` — кнопка «Из YouTube» + диалог с `AiYoutubeTab`; табы из `AiDialog`.

## Риски

- `retryOptions` поддерживается в установленной версии `@google/genai` (проверено по
  докам текущей main, свойства есть в `HttpOptions`); если в установленной версии поля
  нет — fallback: оставить SDK-таймаут, а retry-паузу делать sleep-ом вокруг вызова
  (чистый код, без зависимости от версии).
- Повторная попытка при 503 добавляет ещё один проход разбора видео (до ~90 с) —
  всего хуже 2 попытки + таймаут, иначе «вечная загрузка» как сейчас.
