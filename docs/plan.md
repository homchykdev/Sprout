# Plan: Профиль в стиле Duolingo (финальная навигация)

> Статус: к реализации. Одобрено пользователем по скриншоту Duolingo.
> Предыдущие итерации: 4 таба с настройками в Профиле (отклонено), 5 табов (промежуточная).

## Итоговая навигация
Бар 4 таба: `Сегодня (/) | Тренировки (/plans) | Фото (/gallery) | Профиль (/profile)`.
Настройки — за глобальной шестерёнкой в шапке (уже сделано, не трогаем).

## Экран «Профиль» (/profile) — по мотивам Duolingo
1. Hero: аватар — фото пользователя (IndexedDB) или заглушка-инициал на цветном фоне;
   тап по аватару → меню «Загрузить фото / Убрать фото». Справа от имени ничего —
   шестерёнка глобальная.
   Под именем: «В Пульсе с {since} · Ур. N» (since уже в сторе).
2. Стат-ряд 3 колонки (перенесён из /progress): 🔥 серия · 🏋️ тренировок · ⏱ минут.
3. Секция «НАГРАДЫ ›» — горизонтальная лента круглых иконок бейджей (полученные —
   золотые, ближайшие — приглушённые), вся секция — ссылка на /achievements.
4. Карточка-кнопка «Полная статистика →» (подпись: карта нагрузки, советы, история)
   → /progress.

## Новый экран «Достижения» (/achievements)
Стрелка «›» у Наград ведёт сюда: полный список бейджей (Badges) + челлендж месяца
(MonthlyChallenge). Кнопка «назад» → /profile.

## /progress (полная статистика)
Без счётчиков (переехали в Профиль), без бейджей и челленджа (→ /achievements).
Остались: карта нагрузки 7/30, советы, история. Back-стрелка → /profile.

## Аватар (техника)
- `media.ts`: расширить `Album` на `"avatar"`; константа `AVATAR_ID`; `setAvatarPhoto(blob)`,
  `clearAvatarPhoto()`, `useAvatarPhoto()` (подписка на subs). Галерея аватар не показывает
  (свитчер только progress/goal), в медиа-бэкапы он не попадает — осознанно.
- Загруженное изображение сжимается canvas-ом до 512×512 (cover, JPEG 0.85) — IndexedDB не раздуваем.

## Риски / осознанные решения
- Аватар не входит в медиа-архив бэкапа — при смене устройства пропадёт; отмечено.
- routeTree.gen.ts регенерируется сборкой (в gitignore).
- Соцфункции Duolingo (друзья, забеги) не переносим — их нет в продукте.
