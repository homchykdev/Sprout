## 2. Фото «не видно» — чиним
- Причины: HEIC/HEIF с iPhone принимаются как `image/*`, но браузер их не рисует → битая иконка; плюс в `PhotoTile` нет `onError`-фолбэка.
- Решение: `src/lib/media.ts` `addFiles` — явно скипать HEIC/HEIF (mime + расширение `.heic/.heif`), вернуть в `skipped`; `PhotoTile.tsx` — `onError` на `<img>` → показать `ImageOff` «не удалось показать»; оставить скелетон пока `useBlobUrl` пуст.
- Галерея уже есть (`/gallery`: прогресс-таймлайн + цели-сетка + сравнение 2 фото). Для целей тоже включим выделение/сравнение (сейчас только прогресс).
- Файлы: `media.ts`, `PhotoTile.tsx`, `gallery.tsx`. Тест: unit на фильтр HEIC.

## 3. Несколько фото → автогруппа; короткие видео; webp
- `gallery.tsx` `upload()`: если за раз выбрано ≥2 файлов — после `addFiles` сразу `groupItems(added)` → тост «Группа из N фото создана». Ручное «В группу» через выделение остаётся.
- Фото: `shrink()` в `media.ts` переключаем с `image/jpeg q0.85` на `image/webp q0.82` (fallback jpeg, если webp больше/не поддерживается). Это и есть «webp с сжатием без сильной потери».
- Видео: честно — браузера без ffmpeg.wasm в webp не перекодировать (тяжёлая зависимость, по AGENTS спрашиваю). Делаю: лимит «короткие» — длительность ≤30с и размер ≤50МБ (проверка через `<video>` metadata), иначе тост с отказом; храним как есть (обычно mp4/webm уже сжаты). Если хочешь настоящий транскод — скажи, добавлю ffmpeg отдельным шагом.
- Превью группы: уже есть (звёздочка в `PhotoGroupDialog`, `setCover`), название/заметки/дата у фото остаются — не трогаю, только проверю.
- Файлы: `media.ts` (shrink→webp, `probeVideo`, `addFiles`), `gallery.tsx` (автогруппа). Тест: webp-mime мока canvas.

## 4. Меню «···» + long-press вместо кнопки выделения
- Сейчас в `gallery.tsx`: Upload-загрузить, Link, Download-экспорт, Upload-импорт, ListChecks-выделение.
- Новое: тулбар = `[Загрузить файлы] [···]` + (в режиме выделения — панель действий). В `···` (Radix DropdownMenu, уже в зависимостях): «Добавить по ссылке», «Сохранить архив», «Загрузить архив».
- Long-press: удержание ≥500мс на карточке (pointer events + `setTimeout`, отмена на move/up, вибро `navigator.vibrate(10)`) → вход в `selecting` + выбрать элемент. Работает в `PhotoTimeline` (EntryCard/GroupCard) и сетке целей. Кнопки выделения больше нет.
- Панель в режиме выделения: `Выбрано: N | Выбрать всё | В группу (≥2) | Сравнить (=2) | Удалить | ✕`. Кнопки бэкапа в этом режиме = «Сохранить выбранное»? Нет — бэкап остаётся в `···` (экспорт всего альбома). Если имел в виду экспорт выбранных — скажи, добавлю.
- Удаление: обязательно `AlertDialog` (Radix уже есть) «Удалить N фото навсегда?» [Отмена/Удалить], вместо `confirm()`. Удаление группы = удалить все её items. Применить и в `Viewer` (одиночное удаление тоже через диалог).
- Файлы: `gallery.tsx` (основное), `PhotoTimeline.tsx` (long-press пропсы), `PhotoTile.tsx` (проброс pointer-хендлеров), новый `src/hooks/use-long-press.ts`. Тест: `toGroups` уже есть; добавлю на select-all/логику.
